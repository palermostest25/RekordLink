# RekordLink macOS design

The macOS app follows standard macOS window, toolbar, form, disclosure, menu-bar, and file-panel conventions. It uses semantic system colors, San Francisco typography, SF Symbols, keyboard focus, and system accessibility behavior.

The main window is an operations console rather than a web dashboard. A compact status header shows whether synchronization is running and whether the combined library is ready. Setup is grouped into plainly named native sections. Detailed logs stay behind a disclosure group. The primary action is “Save & Start Sync.”

No decorative gradients, custom window chrome, simulated browser cards, or web navigation patterns are used. Color communicates state and selection. Controls keep standard sizes and spacing so the app remains legible in light mode, dark mode, increased contrast, and larger text settings.
